## Цель работы

Воспроизвести взаимоблокировку и реализовать три подхода к проблеме deadlock: избежание через алгоритм банкира, обнаружение через граф ожидания и предотвращение через контролируемый захват блокировок.

## Что реализовано

- полный алгоритм банкира с `Need`, safety check и `request(pid, vector)`;
- rollback запроса, если состояние становится небезопасным;
- `bank1.txt` и `bank2.txt` с эталонными результатами;
- wait-for graph для единичных ресурсов и поиск цикла DFS;
- `TrackedLock` над `threading.Lock`, который обнаруживает цикл до зависания;
- намеренный `deadlock.py` для демонстрации;
- «обедающие философы»: deadlock, упорядочивание вилок и ограничение `N-1`;
- автоматические тесты.

## Запуск

```bash
python3 banker.py bank1.txt --once
python3 banker.py bank2.txt --once
python3 wait_graph_detector.py journal_deadlock.txt
python3 tracked_deadlock_demo.py
python3 philosophers.py --mode all --duration 1
python3 -m unittest -v
```

## Контрольные результаты

```text
bank1: SAFE: P1 -> P3 -> P4 -> P2 -> P0
bank2: UNSAFE
```

Запрос `P1 (1, 0, 2)` разрешается, а запрос, который переводит систему в unsafe-state, откатывается.

Для журнала с циклом детектор выводит:

```text
P0 -> P1
P1 -> P0
DEADLOCK: P0 -> P1 -> P0
```

## Ключевой вывод

Deadlock требует одновременного выполнения четырёх условий Coffman. Его можно не только обнаруживать, но и предотвращать: например, глобальный порядок захвата ресурсов устраняет circular wait, а алгоритм банкира не разрешает переход в небезопасное состояние.
